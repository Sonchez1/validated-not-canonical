# Results

Generated by `results/analyze.py` from `results/raw/<ecosystem>.jsonl`, which
the harnesses under `harness/` produce. Files:

| file | contents |
|---|---|
| `raw/<ecosystem>.jsonl` | one row per (library, function, case, surface); schema in `harness/SCHEMA.md` |
| `matrix-invisible.md`, `matrix-confusable.md`, `matrix-idna.md`, `matrix-control.md` | per class, one row per function, outcome counts per subclass (R rejected, C canonical, E equivalent, N non-canonical, X invalid, W WHATWG-conformant) |
| `disagreements.md` | per ecosystem and case, the distinct byte strings components hand downstream and which components produced each |
| `findings.json`, `findings.md` | the finding list (see the definition in the top-level README) |
| `summary.json` | the counts the paper uses |

The generated files are withheld from the public repository until each
affected project has responded to the private report or 90 days have passed;
they regenerate locally with one command per ecosystem (see the top-level
README).
